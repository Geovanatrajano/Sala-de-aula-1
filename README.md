# 📚 Sala de Aula — Repositório de Atividades

Bem-vindos ao repositório da nossa sala de aula!

Este espaço foi criado para centralizar as atividades das disciplinas, facilitando o acesso aos conteúdos e a organização das entregas acadêmicas.

Aqui você encontrará os repositórios de cada disciplina, com orientações para realização das atividades e envio das respostas pelo GitHub.

## 🚀 Como utilizar este espaço

1. Escolha a disciplina desejada.
2. Acesse o repositório correspondente.
3. Leia atentamente o enunciado e as orientações de cada atividade.
4. Realize as atividades conforme as instruções fornecidas.
5. Organize suas respostas na pasta identificada com seu nome.
6. Siga as orientações do repositório para enviar sua entrega.

## 💻 Como enviar as atividades

As entregas serão realizadas pelo GitHub, utilizando o fluxo de **Fork e Pull Request**, conforme as instruções de cada disciplina.

De forma geral:

1. Faça um Fork do repositório da disciplina para sua conta GitHub.
2. Crie ou edite os arquivos das atividades na sua cópia, dentro da sua pasta pessoal.
3. Salve e registre as alterações.
4. Abra um Pull Request para o repositório original, permitindo a revisão das respostas.

Consulte sempre o README específico de cada disciplina para obter as orientações completas.

## ⚠️ Orientações importantes

- Utilize sua própria pasta para armazenar as respostas.
- Não altere os arquivos de outros alunos.
- Mantenha os arquivos organizados e com nomes claros.
- Confira se sua entrega está completa antes de abrir o Pull Request.
- Respeite os prazos estabelecidos para cada atividade.
- Em caso de dúvida, consulte as orientações da atividade.

## 🎯 Nosso objetivo

Desenvolver conhecimentos técnicos, estimular a autonomia dos alunos e praticar ferramentas utilizadas no desenvolvimento de software, como Git e GitHub, mantendo as atividades acadêmicas organizadas e acessíveis.
