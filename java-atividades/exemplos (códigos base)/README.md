# ☕ Exemplos de Código Java

Esta pasta reúne exemplos de códigos em Java disponibilizados para auxiliar nos estudos e na realização das atividades da disciplina.

Os arquivos estão organizados em pastas, permitindo consultar diferentes exemplos e compreender como os conceitos da linguagem são aplicados na prática.

## 🎯 Objetivo

O objetivo desta pasta é servir como material de apoio para que os alunos possam estudar os exemplos, compreender sua estrutura e utilizá-los como referência durante o desenvolvimento das atividades.

## 📚 Como utilizar os exemplos

1. Acesse as pastas disponíveis e escolha o exemplo que deseja estudar.
2. Abra os arquivos `.java` e leia o código com atenção.
3. Observe a declaração das classes, os atributos, os métodos e a criação dos objetos.
4. Execute os exemplos, quando possível, para observar seus resultados.
5. Utilize o conhecimento adquirido para desenvolver suas próprias soluções.

## 💻 Conceitos que podem ser estudados

Os exemplos podem ajudar na compreensão de conceitos como:

- Declaração e organização de classes;
- Atributos e métodos;
- Criação e utilização de objetos;
- Construtores;
- Parâmetros e retorno de métodos;
- Estruturas condicionais e de repetição;
- Organização e execução de programas Java.

Consulte cada arquivo para identificar os conceitos efetivamente demonstrados naquele exemplo.

## ⚠️ Orientações importantes

- Os códigos são materiais de referência para estudo e aprendizagem.
- Leia e compreenda o código antes de utilizá-lo.
- Experimente modificar os exemplos para testar seu entendimento.
- Não copie os códigos sem compreender seu funcionamento.
- Utilize os exemplos como apoio, desenvolvendo suas próprias soluções para as atividades propostas.
- Siga as orientações específicas de cada atividade e da professora.

## 🚀 Aprenda praticando!

Estudar exemplos é uma ótima maneira de aprender programação. Leia, execute, experimente modificações e aplique o que aprendeu na resolução dos exercícios.

**Bons estudos e boa programação!** ☕
