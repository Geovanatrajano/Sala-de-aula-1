# 📚 Atividades de Java

Bem-vindos ao repositório de atividades da disciplina de **Java**!

Este repositório foi criado para organizar as atividades da disciplina, disponibilizar os enunciados e facilitar a entrega das respostas dos alunos.

## 📁 Organização do repositório

Cada pasta deste repositório corresponde a uma atividade. Dentro dela, você encontrará o enunciado e as orientações necessárias para sua realização.

A pasta `respostas` contém uma pasta com o nome de cada aluno. É dentro da sua própria pasta que você deverá criar os arquivos com as respostas das atividades.

**Atenção:** cada aluno deve editar e adicionar arquivos somente dentro da pasta que corresponde ao seu nome.

## ✏️ Como responder às atividades

Para entregar as atividades, siga as orientações abaixo.

### 1. Localize sua pasta

Acesse a pasta `respostas` e procure a pasta com seu nome.

Por exemplo:

`respostas/Gabriela Alves/`

### 2. Crie um arquivo para cada atividade

Para cada atividade, crie um arquivo dentro da sua pasta, utilizando o número da atividade no nome do arquivo.

Você pode utilizar:

- **`.md`** — para respostas escritas, explicações, algoritmos e documentação.
- **`.java`** — para códigos desenvolvidos em Java.

**Exemplo:** se você estiver respondendo à Atividade 1, crie o arquivo correspondente dentro da sua pasta:

```text
respostas/
└── Gabriela Alves/
    └── atividade1.md
```

Se a resposta exigir um programa em Java, utilize:

```text
respostas/
└── Gabriela Alves/
    └── atividade1.java
```

Use a extensão adequada ao conteúdo da atividade. Se for necessário entregar uma resposta escrita e um código, você poderá criar os dois arquivos.

### 3. Como organizar atividades maiores

Quando uma atividade exigir vários arquivos, como um documento `.md` e um código `.java`, você poderá criar uma pasta específica para aquela atividade dentro da sua pasta pessoal.

Por exemplo, para a Atividade 2:

```text
respostas/
└── Gabriela Alves/
    ├── atividade1.md
    └── atividade2/
        ├── resposta.md
        └── Main.java
```

Dessa forma, todos os arquivos referentes à Atividade 2 ficam organizados juntos, facilitando a leitura e a correção.

Você também poderá incluir outros arquivos, caso sejam solicitados no enunciado.

## 💻 Como enviar suas respostas pelo GitHub

1. Acesse o repositório e abra a pasta `respostas`.
2. Entre na pasta com seu nome.
3. Crie o arquivo ou a pasta correspondente à atividade.
4. Escreva sua resposta ou adicione o código solicitado.
5. Salve as alterações seguindo o procedimento de entrega definido pela professora.

As respostas deverão ser enviadas por meio de um **Fork e Pull Request**, quando essa for a forma de entrega adotada para a turma. Nesse caso, você deverá criar uma cópia do repositório na sua conta, realizar as alterações na sua cópia e abrir um Pull Request para que a professora possa revisar seu trabalho.

## ⚠️ Orientações importantes

- Não altere os arquivos de outros alunos.
- Não coloque suas respostas fora da pasta que contém seu nome.
- Utilize nomes claros e padronizados para os arquivos.
- Leia o enunciado antes de iniciar cada atividade.
- Verifique se os arquivos foram salvos corretamente antes de enviar a entrega.
- Confira os prazos e as instruções específicas de cada atividade.

## 🎯 Objetivo

Manter as atividades organizadas, facilitar o acompanhamento dos trabalhos e desenvolver boas práticas de organização de arquivos e utilização do GitHub.
