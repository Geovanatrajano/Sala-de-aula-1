# 📐 Atividades de Modelagem de Sistemas

Bem-vindos ao repositório de atividades da disciplina de **Modelagem de Sistemas**!

Este repositório foi criado para organizar as atividades da disciplina, disponibilizar os enunciados e facilitar a entrega das respostas e dos documentos produzidos pelos alunos.

## 📁 Organização do repositório

Cada pasta deste repositório corresponde a uma atividade. Dentro dela, você encontrará o enunciado e as orientações necessárias para sua realização.

A pasta `respostas` contém uma pasta com o nome de cada aluno. É dentro da sua própria pasta que você deverá criar os arquivos com as respostas das atividades.

**Atenção:** cada aluno deve criar e organizar seus arquivos somente dentro da pasta que corresponde ao seu nome.

## ✏️ Como responder às atividades

### 1. Localize sua pasta

Acesse a pasta `respostas` e procure a pasta com seu nome.

Por exemplo:

`respostas/Gabriela Alves/`

### 2. Crie um arquivo para cada atividade

Para cada atividade, crie um arquivo dentro da sua pasta, utilizando o número da atividade no nome do arquivo.

Dependendo do que for solicitado no enunciado, você poderá utilizar diferentes formatos:

- **`.md`** — para respostas escritas, requisitos, especificações, justificativas e documentação.
- **`.puml`** — para diagramas criados com PlantUML.
- **`.png`, `.svg` ou `.pdf`** — para diagramas exportados e documentos, quando solicitados.
- **Outros formatos** — conforme as orientações específicas da atividade.

**Exemplo:** se a Atividade 1 solicitar um documento com requisitos funcionais e não funcionais, crie:

```text
respostas/
└── Gabriela Alves/
    └── atividade1.md
```

Se a atividade solicitar um diagrama de casos de uso feito com PlantUML, você poderá criar:

```text
respostas/
└── Gabriela Alves/
    ├── atividade1.md
    └── atividade2.puml
```

### 3. Como organizar atividades maiores

Quando uma atividade exigir vários arquivos, como documentação, diagramas e justificativas, você poderá criar uma pasta específica para aquela atividade dentro da sua pasta pessoal.

Por exemplo:

```text
respostas/
└── Gabriela Alves/
    ├── atividade1.md
    └── atividade2/
        ├── resposta.md
        ├── diagrama-casos-de-uso.puml
        ├── diagrama-casos-de-uso.png
        ├── diagrama-de-classes.puml
        └── diagrama-de-classes.png
```

Dessa forma, todos os arquivos referentes à Atividade 2 ficam organizados juntos, facilitando a consulta e a correção.

Você poderá incluir outros documentos, diagramas e arquivos editáveis quando forem solicitados no enunciado.

## 📝 Orientações para os diagramas

Ao elaborar diagramas e modelos, siga estas recomendações:

- Utilize a notação adequada ao tipo de diagrama solicitado.
- Mantenha os nomes de classes, atores, entidades e relacionamentos legíveis.
- Verifique se os diagramas estão coerentes com os requisitos descritos.
- Quando utilizar PlantUML, entregue o arquivo `.puml` para permitir a edição do diagrama.
- Inclua também uma versão exportada em PNG, SVG ou PDF quando solicitado.
- Revise os arquivos antes de realizar a entrega.

## 💻 Como enviar suas respostas pelo GitHub

1. Acesse o repositório e abra a pasta `respostas`.
2. Entre na pasta com seu nome.
3. Crie o arquivo ou a pasta correspondente à atividade.
4. Adicione sua documentação, seus diagramas e os demais arquivos solicitados.
5. Salve as alterações seguindo o procedimento de entrega definido pela professora.

As respostas deverão ser enviadas por meio de um **Fork e Pull Request**, quando essa for a forma de entrega adotada para a turma. Nesse caso, você deverá criar uma cópia do repositório na sua conta, realizar as alterações na sua cópia e abrir um Pull Request para que a professora possa revisar seu trabalho.

## ⚠️ Orientações importantes

- Não altere os arquivos de outros alunos.
- Não coloque suas respostas fora da pasta que contém seu nome.
- Utilize nomes claros e padronizados para os arquivos.
- Leia atentamente o enunciado antes de iniciar cada atividade.
- Confira se os documentos e diagramas estão completos e legíveis.
- Verifique se os arquivos foram salvos corretamente antes de enviar a entrega.
- Respeite os prazos e as instruções específicas de cada atividade.

## 🎯 Objetivo

Manter as atividades organizadas, desenvolver boas práticas de documentação e modelagem de sistemas e facilitar o acompanhamento dos trabalhos realizados ao longo da disciplina.
